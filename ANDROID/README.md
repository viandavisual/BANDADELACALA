# BANDA DE LA CALA · Android wrapper

Aquest directori conté el wrapper Android de **BANDA DE LA CALA APP** dins del mateix repositori principal del projecte.

- Package ID: `com.viandavisual.bandadelacala`
- Web app: `https://bandadelacala.viandavisual.com`
- El codi viu de l'APP continua allotjat a la web/GitHub Pages.
- Els canvis normals d'HTML, CSS, JavaScript, assets i Supabase no requereixen regenerar l'APK.
- L'APK de release es genera amb GitHub Actions.

## Important

No pugis mai el keystore de signatura ni les seves contrasenyes al repositori. La signatura s'ha de configurar mitjançant GitHub Actions Secrets.
